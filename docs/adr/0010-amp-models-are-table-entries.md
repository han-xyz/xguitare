# Amp models are entries of one data table, chosen by a numbered Parameter

The `amp` Module (`crates/xguitare-dsp/src/modules/amp.rs`) holds no amplifier of its own. Each Amp model is one entry of `MODELS` in `crates/xguitare-dsp/src/amp_model.rs`: its gain stages (high-pass, optional low shelf, gain, `tanh` shaper with a bias, low-pass), the `gain` pot's loss and bright cap, which stage the tone stack follows, the tone stack's kind and values, and the power amp's facts. The `model` Parameter is the entry's position in the table. Its labels are the entries' names (`MODEL_LABELS`, filled from the table at compile time), and its range is the table's length, so an Amp model on an existing tone stack kind is added by appending one entry to that file. The table is append-only: a Preset stores `model` as a number (ADR-0008), so an entry is never removed, renamed or moved.

Considered and rejected: the amp spread over the existing `preamp` and `tonestack` Modules and a new power amp Module (one amp would live in three tables and three Rack units, and the owner chose one Module); one Rust type per amp behind a trait (stage, stack and power amp code copied per amp, and each amp needing its own tests and registry entry); neural captures (an inference dependency beyond `realfft`, capture files with their own licences, and a CPU cost the callback budget has not been measured for); a circuit solver per amp (wave digital filters or nodal analysis need a netlist and a solver for each amp, where static waveshaping with oversampling plus digital filters for the linear parts is the simplest form that works); storing `model` in Presets by label instead of number (sturdier than append-only, but it changes Preset parsing for every choice Parameter of every Module).

What it costs. The stage shape cannot express circuits outside it, such as a clipping cathode follower's asymmetry, an effects loop or channel mixing. A new tone stack kind is new code in `amp.rs`, not data. The table's order is frozen for good. A Parameter an Amp model lacks still shows (an amp with a fixed mid position ignores `middle`). A Preset from a newer build whose `model` is past this build's last entry is clamped to the last Amp model without a warning, as every choice Parameter is.
