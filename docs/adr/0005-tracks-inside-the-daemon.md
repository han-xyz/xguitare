# Recording runs inside the Daemon: a Project's Tracks each own a Rack

The DAW is not a second program. When a Project is open the Daemon's Engine runs up to sixteen Tracks, each with its own Rack, input port, volume, pan, mute, solo and arm, summed to the existing stereo output (how Tracks, Buses and Master are mixed is ADR-0007); with no Project open the Engine runs one Rack exactly as before, so the live amp, Presets, the Bank and MIDI program change are untouched. Takes store the dry input and the Track's Rack is applied on playback (re-amping), so tone can change after recording. This reuses the JACK client, the Control API, the realtime discipline and the GUI, and keeps one audio thread that already meets its deadline; the cost is a heavier Engine (a Project graph beside the single Rack) and a Daemon that writes audio files. A separate DAW fed over JACK was considered (two programs, two transports to keep in step); hosting xguitare as a plugin in another DAW is kept as a later export of the I/O-free DSP crate, not a replacement.
